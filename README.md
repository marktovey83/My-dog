# Smart Hazel Designs

By Smarty and Hazel.

Website-first store for dog profiles, styled looks, and dropshipped toys, accessories, and treats across Australia.

Repo: https://github.com/marktovey83/My-dog

## Start here

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Pages

- `index.html` — home
- `profile.html` — dog profile + style the look
- `shop.html` — starter catalogue (dropship placeholders)

## Model

Dropship only for now. No warehouse stock.

Suggested AU suppliers:

1. Agline / Southern Pet Supplies — food, toys, accessories
2. Aussie Dog Products — Australian-made toys
3. Dropship Zone — beds, bowls, toys, apparel
